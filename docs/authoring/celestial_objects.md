## Naming and Placement



their children object folders are placed next to it's parent index.

e.g.:
~~~text
📁 star-name        # <-- Star and contain its planetary system
    📃 index.md     # <-- Star's index
    📁 _misc        # <-- Star's misc files
    📂 body-name    # <-- Planet A
    📂 body-name    # <-- Planet B
~~~

#### 📁 body-name

the folder for planets, moon, asteroid, comet. Basically celestial **bodies**, or anything that cant produce their own light naturally.
